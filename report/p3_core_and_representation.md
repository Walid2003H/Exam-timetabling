# القسم الثالث من التقرير: بنية النواة الحسابية وتمثيل الحلول والتقييم التفاضلي

## 1. تمثيل المسألة والحلول في الذاكرة (Representation & CSR Graph)

يُجسَّد كل جدول امتحانات مرشح بمتجه أعداد صحيحة متجاور في الذاكرة $x \in \{0, 1, \dots, T-1\}^N$ من النوع `int32`، حيث يحدد العنصر $x_i$ الفترة الزمنية المسندة للامتحان $i$. يمتاز هذا التمثيل المباشر (Direct Slot Encoding) بكونه يضمن تلقائياً إسناد فترة وحيدة لكل امتحان، ويسمح بالاستعلام عن فترة أي امتحان في زمن $O(1)$.

في المقابل، يُخزَّن بيان التعارض $G = (E, \mathcal{E}, C)$ داخل الكائن غير القابل للتعديل `Instance` بصيغة الصفوف المتفرقة المضغوطة (Compressed Sparse Row - CSR) عبر ثلاث مصفوفات أحادية البعد من النوع `int32`:
- `indptr` بطول $N + 1$: يحدد بداية ونهاية جيران كل امتحان $i$ في المصفوفتين التاليتين، وتكون درجة الامتحان $\deg(i) = 	ext{indptr}[i+1] - 	ext{indptr}[i]$.
- `indices` بطول $2|\mathcal{E}|$: تحفظ أرقام الامتحانات المجاورة لكل امتحان.
- `weights` بطول $2|\mathcal{E}|$: تحفظ عدد الطلاب المشتركين $c_{ij}$ الموافق لكل جار في `indices`.

يتيح هذا التمثيل المرور على جيران الامتحان $i$ في حلقة متجاورة في الذاكرة الكاش (Cache-friendly loop) بتعقيد $O(\deg(i))$ بدلاً من مسح صف كامل بطول $N$ في مصفوفة كثيفة.

## 2. التقييم الكامل والتقييم التفاضلي السريع (`delta_move`)

في التقييم الكامل (`proximity_cost` و `violation_weight`)، تمسح النواة المترجمة بـ Numba الحواف في المثلث العلوي ($j > i$) مرة واحدة فقط لتجنب مضاعفة الحساب، وتحسب وزن Carter عبر الإزاحة الثنائية `1 << (5 - d)` للمسافات $1 \le d \le 5$ بتعقيد $O(|\mathcal{E}|)$.

أما في البحث المحلي والخوارزميات الميميتية، فإن تعديل فترة امتحان واحد $i$ من $s_{	ext{old}} = x_i$ إلى $s_{	ext{new}}$ لا يؤثر إلا على الحواف المرتبطة بالامتحان $i$ نفسه. تحسب الدالة `_delta_move_kernel` التغيرين $(\Delta f, \Delta V)$ في زمن $O(\deg(i))$ دون تعديل المتجه $x$:

```text
Algorithm 2: Incremental Delta Evaluation (delta_move)
Input: Instance inst (CSR), timetable x, exam index i, candidate slot s_new
Output: (delta_f, delta_V)

1: s_old <- x[i]
2: if s_old == s_new then return (0.0, 0.0)
3: delta_raw_f <- 0, delta_V <- 0
4: for k = inst.indptr[i] to inst.indptr[i + 1] - 1 do
5:     j <- inst.indices[k], w_ij <- inst.weights[k], s_j <- x[j]
6:     d_old <- |s_old - s_j|
7:     if d_old == 0 then delta_V <- delta_V - w_ij
8:     else if d_old <= 5 then delta_raw_f <- delta_raw_f - w_ij * 2^(5 - d_old)
9:     d_new <- |s_new - s_j|
10:    if d_new == 0 then delta_V <- delta_V + w_ij
11:    else if d_new <= 5 then delta_raw_f <- delta_raw_f + w_ij * 2^(5 - d_new)
12: return (delta_raw_f / inst.n_students, delta_V)
```

وتُحتسب كلفة هذه العملية في ميزانية التقييمات العادلة (`Budget.charge_delta`) بمقدار $
rac{\deg(i)}{|\mathcal{E}|}	ext{ FEE}$، بحيث يكافئ فحص حركة واحدة لكل امتحان في البيان تقييماً كاملاً واحداً تقريباً.

## 3. آلية إصلاح التعارضات (`repair`) وقياس التنوع (`diversity`)

نظراً لأن التوليد العشوائي أو مشغلات التصالب والطفرة قد تنتج جداول تنتهك القيد الصلب ($V(x) > 0$)، توفر النواة مشغّل إصلاح هجيناً في `repair(inst, x, rng, max_passes)`:
1. **طور الانحدار الجشع المحدّث تزايدياً:** يبني المشغّل مصفوفة `slot_table[i, s]` التي تمثل مجموع أوزان تعارض الامتحان $i$ مع الامتحانات الموجودة حالياً في الفترة $s$. وفي كل جولة، يمر على الامتحانات المتعارضة بترتيب عشوائي وينقل كلاً منها إلى الفترة ذات التعارض الأدنى (مع كسر التعادل بأقل كلفة تقارب $f$)، ويحدّث `slot_table` لجيران الامتحان المنقول فقط في زمن $O(\deg(i))$.
2. **طور البحث المحظور القصير (Tabu-Assisted Min-Conflicts):** إذا بقيت تعارضات عالقة في نهاية محلية للطور الجشع، ينفذ المشغّل خطوات بحث محظور قصيرة تمنع إعادة الامتحان إلى فترته السابقة لعدد محدود من الخطوات ما لم يحقق معيار الطموح (Aspiration Criterion) بخفض أفضل وزن انتهاكات مسجّل.

ولمراقبة سلوك الخوارزميات السكانية (GA, PSO, ACO) والتحقق من عدم وقوعها في تقارب مبكر، تحسب الدالة `diversity(X)` متوسط مسافة هامينغ المطبّعة بين جميع أزواج الحلول في المجتمع $X \in \mathbb{Z}^{K 	imes N}$:
$$D(X) =
rac{2}{K(K-1)N} \sum_{a=0}^{K-2} \sum_{b=a+1}^{K-1} \sum_{i=0}^{N-1} \mathbb{I}[X_{a,i}
eq X_{b,i}] \in [0, 1]$$
ويتم تسجيلها دورياً كل $0.5\%$ من الميزانية عبر المسجّل `Tracker`.
