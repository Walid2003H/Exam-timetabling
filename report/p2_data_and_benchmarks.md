# القسم الثاني من التقرير: توليد البيانات وخصائص مجموعات الاختبار

## 1. منهجية توليد المسائل الاصطناعية (Planted-Solution Cohort Generator)

تتطلب المقارنة المنهجية بين خوارزميات جدولة الامتحانات توفر مسائل اختبار متدرجة الحجم وقابلة لإعادة الإنتاج باستخدام بذور عشوائية مثبتة، مع ضمان وجود جدول مقبول يحقق قيد عدم التضارب $V(x) = 0$ ضمن عدد الفترات المتاحة $T$. فالتوليد العشوائي غير المقيد لحواف التعارض قد يرفع العدد اللوني للبيان $\chi(G)$ فوق $T$، مما يجعل المسألة غير قابلة للحل أصلاً.

لمعالجة ذلك، يعتمد المولّد في `src/data/generator.py` على نموذج التلوين المزروع المقترن بالدفعات الدراسية (Planted-Coloring Cohort Model) عبر الخطوات التالية باستخدام المولد المعزول `np.random.default_rng(seed)`:
1. **إسناد الفترات المرجعية والمسارات الدراسية:** تُوزّع الامتحانات $N$ بشكل متوازن وعشوائي على الفترات $T$ لتشكيل جدول مرجعي مخفي $x^{\text{planted}} \in \{0, \dots, T-1\}^N$، كما تُوزّع على $C$ مسارات دراسية (`n_cohorts`) تمثل الأقسام أو المستويات الجامعية.
2. **توليد أوزان شعبية الامتحانات:** يُسحب لكل امتحان وزن شعبية من توزيع $\text{Gamma}(2, 1)$ لتمثيل التفاوت بين المواد المشتركة الكبيرة والمواد التخصصية، وتُحسب مصفوفة احتمالات اختيار الفترات والامتحانات لكل مسار دراسي مسبقاً.
3. **توليد سجلات الطلاب مع ضمان تغطية جميع الامتحانات:** يسجل كل طالب $s \in \{0, \dots, S-1\}$ في $k_s$ فترات زمنية مختلفة دون تكرار، ويختار امتحاناً واحداً من كل فترة مختارة (مع ضمان تغطية جميع الامتحانات $N$ في أول $N$ سجل طلابي دون كسر شرط اختلاف الفترات). وبما أن الطالب لا يختار أبداً امتحانين يقعان في نفس الفترة المرجعية، فإن $c_{ij} = 0$ لكل زوج امتحانات يشتركان في الفترة المزروعة نفسها، ومن ثم يتحقق حتماً:
$$V(x^{\text{planted}}) = 0$$
4. **بناء تمثيل CSR:** تُجمع أوزان التقاطع $c_{ij}$ من سجلات الطلاب، ثم تُحوّل المصفوفة المتناظرة إلى مصفوفات CSR (`indptr`, `indices`, `weights`) من النوع `int32`، ويُحفظ الجدول المزروع في `meta["planted_solution"]` لأغراض التحقق فقط دون استخدامه في الخوارزميات.

### الخوارزمية التوضيحية للمولّد (Pseudo-code)

```text
Algorithm 1: Planted-Cohort Synthetic Instance Generator
Input: n_exams N, n_slots T, n_students S, courses_per_student k_avg, n_cohorts C, seed
Output: Instance in CSR format

1: rng <- default_rng(seed)
2: planted_x <- shuffle([0, 1, ..., N-1] mod T, rng)
3: cohort <- shuffle([0, 1, ..., N-1] mod C, rng)
4: Precompute slot weights W_slot[c, t] and exam probabilities P_exam[c, t]
5: Initialize conflict_matrix[N, N] <- 0, exam_size[N] <- 0
6: coverage_order <- permutation(N, rng)
7: for s = 0 to S - 1 do
8:     c <- s mod C
9:     k <- UniformInt(k_avg - 1, k_avg + 1, rng)
10:    chosen_slots <- SampleWithoutReplacement(0..T-1, size=k, p=W_slot[c], rng)
11:    if s < N and planted_x[coverage_order[s]] not in chosen_slots then
12:        chosen_slots[k - 1] <- planted_x[coverage_order[s]]
13:    chosen_exams <- SelectOneExamPerSlot(chosen_slots, coverage_order, s, P_exam[c], rng)
14:    Update exam_size and conflict_matrix for all pairs in chosen_exams
15: indptr, indices, weights, n_edges <- ConvertToCSR(conflict_matrix)
16: return Instance(N, S, T, indptr, indices, weights, exam_size, n_edges)
```

يتولى الملف `src/data/toronto_parser.py` قراءة ملفات معيار تورونتو القياسية (`.crs` و `.stu`). يقرأ المحلل معرفات الامتحانات وأعداد التسجيل المعلنة من `.crs`، ثم يبني أوزان التعارض $c_{ij}$ وأعداد التسجيل الفعلية من سجلات الطلاب في `.stu` بعد إزالة أي تكرار داخل سطر الطالب الواحد، ويرفض أي رمز مادة غير معرّف في `.crs`. تبلغ كلفة تجميع الأزواج $O(S \cdot k^2)$ حيث $k$ متوسط عدد مواد الطالب.
