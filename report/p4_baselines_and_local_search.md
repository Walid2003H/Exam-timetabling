# القسم الرابع من التقرير: خطوط الأساس، ووحدة البحث المحلي المشتركة

## 1. هياكل الجوار ووحدة البحث المحلي المشتركة (`src/local_search/`)

لضمان عدالة المقارنة بين الخوارزميات السكانية الثلاث عند تزويدها بالبحث المحلي (`ga_memetic`, `pso_memetic`, `aco_memetic`)، صُممت وحدة بحث محلي مشتركة في `src/local_search/` تلتزم بخصم كل تقييم جزئي عبر `Budget.charge_delta` وتوفر ثلاثة مشغلات جوار متكاملة:
1. **جوار نقل الامتحان المنفرد (`move_ls`):** يفحص نقل امتحان $i$ من فترته الحالية $x_i$ إلى فترة بديلة $s_{	ext{new}}
eq x_i$ باستخدام `delta_move` بتعقيد $O(\deg(i))$، ويقبل الحركة إذا خفضت وزن الانتهاكات ($\Delta V < 0$) أو حافظت على المقبولية ($\Delta V = 0$) مع خفض كلفة التقارب ($\Delta f < 0$).
2. **جوار مبادلة الامتحانين (`swap_ls`):** يختار زوجاً من الامتحانات $(i, j)$ في فترتين مختلفتين ويحسب الأثر الصافي لمبادلتهما عبر استدعاءين متتاليين لدالة `delta_move` بتعقيد $O(\deg(i) + \deg(j))$، مما يراعي بدقة أي حافة تعارض مباشرة تربط بين $i$ و $j$.
3. **جوار سلاسل كيمب (`kempe_ls`):** في الجداول الكثيفة، غالباً ما يتعذر نقل امتحان واحد دون إحداث تعارض صلب. لحل ذلك، يستخرج المشغّل المركّبة المتصلة $K$ للامتحان البذرة $i$ في البيان الجزئي المستحث بالامتحانات المسندة إلى الفترتين $\{x_i, s_{	ext{target}}\}$ عبر البحث بالعرض (BFS)، ثم يبدّل الفترتين لجميع رؤوس $K$. وبما أن المسافات الزمنية بين الرؤوس الداخلية في $K$ لا تتغير، يُحسب التغير $(\Delta f, \Delta V)$ عبر مسح الحواف الحدودية $(u \in K, v
otin K)$ فقط.

```text
Algorithm 3: Hybrid Memetic Local Search (intensify)
Input: Instance inst, timetable x, FEE budget, RNG rng, max_passes, kempe_steps, swap_trials
Output: Locally refined timetable x

1: x <- move_ls(inst, x, budget, rng, max_passes, first_improvement=True)
2: if not budget.exhausted then
3:     x <- kempe_ls(inst, x, budget, rng, max_steps=kempe_steps)
4: if not budget.exhausted then
5:     x <- swap_ls(inst, x, budget, rng, max_trials=swap_trials)
6: if not budget.exhausted then
7:     x <- move_ls(inst, x, budget, rng, max_passes=1, first_improvement=True)
8: return x
```

## 2. الخوارزميات المرجعية الأربعة (`src/baselines/`)

1. **البحث العشوائي المُصلَح (`random`):** يولّد جداول عشوائية مستقلة ويطبّق عليها مشغّل الإصلاح `repair`، ويحتفظ بأفضل جدول مقبول وُجد قبل نفاد ميزانية FEE. يمثّل هذا الحلّال الحد الأدنى المرجعي الذي ينبغي لكل خوارزمية ذكية التفوق عليه.
2. **خوارزمية درجة التشبع المتعددة الانطلاقات (`dsatur`):** تبني الجدول خطوة بخطوة وفق مؤشر Brélaz (1979) عبر اختيار الامتحان غير المجدول ذي أكبر عدد من الفترات المختلفة المحجوزة لدى جيرانه، مع كسر التعادل بالدرجة الساكنة ثم بعشوائية مضبوطة، وإسناده إلى الفترة الخالية من التعارض التي تضيف أقل كلفة تقارب آنية (`min_proximity`).
3. **التلدين المحاكى الهجين (`sa`):** ينطلق من أفضل جدول ابتدائي من عدة بناءات لـ `dsatur`، ثم يستكشف الفضاء عبر مزيج احتمالي من حركات النقل المفردة (بنسبة $1 - p_{	ext{kempe}}$) وسلاسل كيمب (بنسبة $p_{	ext{kempe}} = 0.25$). تُقبل الحركات المحسّنة دائماً، وتُقبل الحركات المدهورة لكلفة التقارب ضمن الفضاء المقبول ($\Delta V = 0, \Delta f > 0$) وفق احتمال متروبوليس $\exp(-\Delta f / T_{	ext{temp}})$ مع جدول تبريد هندسي $T_{k+1} = lpha T_k$ ($lpha = 0.96$) وآلية إعادة تسخين عند الركود.
4. **التفريع والتحديد الدقيق (`exact`):** مخصص لمجموعة المسائل الصغيرة (`Tiny`, $N=12, T=6$) لقياس فجوة الأمثلية (Optimality Gap). يبدأ بالحصول على حد علوي قوي $U$ عبر `dsatur + move_ls`، ثم يرتب الامتحانات تنازلياً حسب تشبع الجيران والدرجة، ويكسر تناظر الألوان على الامتحان الأول، ويشذب أي فرع جزئي تتجاوز كلفته المتراكمة الحد العلوي $U$ أو ينتهك القيد الصلب.
